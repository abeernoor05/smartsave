# SmartSave 🔖

> Never let a saved internship, job, or scholarship deadline disappear again.

Built by **Team BitHeads** for the **YMF × Bilt.me Hackathon**.

## The Problem

We all save links and reels meaning to come back to them: internships, travel ideas, online courses, articles. Instead, they pile up unorganized in chats and camera rolls, and deadlines quietly slip by. Real opportunities are lost simply because they never resurfaced on time.

## The Solution

SmartSave **extracts, categorizes, and reminds**, automatically.

| Step | What it does |
|------|--------------|
| **Extract** | Share any link or reel to SmartSave and the content is pulled in automatically. |
| **Categorize** | AI sorts each save into Career, Travel, Learning, or General, with no manual filing. |
| **Remind** | Set your own reminder, or let SmartSave detect deadlines and nudge you automatically. |

One tap to save, zero effort to remember.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router (navigation)
- AsyncStorage (local data persistence)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- [Expo Go](https://expo.dev/go) on your phone (optional, for testing on a device)

### Installation

```bash
git clone https://github.com/abeernoor05/smartsave.git
cd smartsave
npm install
```

### Run the app

```bash
npx expo start
```

Scan the QR code with Expo Go, or press `i` (iOS simulator) or `a` (Android emulator).
